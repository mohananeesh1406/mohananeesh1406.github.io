# Mohan Aneesh Sai Pusarla — Robotics Portfolio

A responsive, dark robotics-themed portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — complete website
- `resume.pdf` — add your resume PDF here if you want the résumé button to work

## Before publishing
1. Replace every `YOUR-USERNAME` and example repository path with your actual GitHub username and repository URLs.
2. Replace `REPORT-URL-REPLACE-ME` with the e-Yantra report URL.
3. Replace the LinkedIn homepage URL with your profile URL.
4. Add `resume.pdf` to this folder, or change/remove the résumé button.
5. Consider adding real project photos, CAD screenshots, simulation screenshots, and diagrams.

## Publish on GitHub Pages
1. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html` (and optionally `resume.pdf`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, visit `https://YOUR-USERNAME.github.io/`.

The site is static and does not require a build step or package installation.
